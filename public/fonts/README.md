# Reading font files

These Latin WOFF2 files come from Fontsource variable font packages. The app
serves them locally and does not contact a font service at runtime.

| Font | Fontsource package version |
| ---- | -------------------------- |
| Newsreader | `5.2.10` |
| Literata | `5.2.8` |
| Source Serif 4 | `5.2.9` |
| Atkinson Hyperlegible Next | `5.2.6` |
| JetBrains Mono | `5.2.8` |

Each font's license is in the matching `LICENSE-*.txt` file.
